# lowvram: benchmarks and paper

This folder holds the evaluation of lowvram: the benchmark suite, its raw results and
the paper written from them. The lowvram tool itself is the two files at the repository
root (`lowvram.c`, `Makefile`).

```
docs/
├── README.md            this file
├── bench/               benchmark suite (uv project) and results
│   ├── README.md        how to run, what each benchmark measures, result format
│   ├── common.py        timing, machine metadata, result output, CUDA driver hints
│   ├── micro.py         synthetic: PCIe, GEMM, working-set sweep, layer stack
│   ├── yue2.py          real model with two execution paths (YuE2-3B)
│   ├── llm.py           real dense language model (any Hugging Face causal LM)
│   ├── run_all.sh       the full matrix, one fresh process per configuration
│   ├── plot.py          results -> figures, LaTeX tables and numbers, summary.md
│   ├── results/         raw results (*.jsonl) and summary.md
│   └── models/          downloaded model weights (git-ignored)
└── paper/               paper draft (LaTeX)
    ├── README.md        how to build, how numbers get into the text
    ├── paper.tex
    ├── references.bib
    ├── figures/         generated by bench/plot.py
    └── generated/       generated by bench/plot.py: numbers.tex and tables
```

## From measurement to paper

```sh
cd docs/bench
./run_all.sh              # ~1.5 h; appends to results/<run id>.jsonl
uv run python plot.py     # -> ../paper/figures, ../paper/generated, results/summary.md
make -C ../paper          # -> ../paper/paper.pdf
```

No number in the paper is typed by hand: the text uses macros from
`paper/generated/numbers.tex`, which `plot.py` writes from the raw results. A new
benchmark run therefore updates every figure, table and quoted number at once.

## What is committed

| Committed | Not committed (`.gitignore`) |
|---|---|
| benchmark code, `pyproject.toml`, `uv.lock` | `bench/.venv/` (PyTorch etc., ~5.5 GB) |
| raw results `bench/results/*.jsonl` and `summary.md` | `bench/models/` (model weights, ~8 GB) |
| paper sources, figures, `paper/generated/` | console logs `bench/results/*.log` |
| | LaTeX build files and `paper/paper.pdf` |

The benchmarks live in the same repository as the tool on purpose: every result records
the lowvram commit it measured (`env.lowvram_commit`), so code and evidence stay
together and a reader can check out exactly what was measured. Large media (videos,
recordings) should not go in git; publish the paper PDF as a release asset or on arXiv.

Each result records the machine's CPU, GPU, driver and software versions, but not its
host name or any user name.
